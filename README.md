# 오늘의 성경읽기 웹앱

- 날짜를 선택하면 `readings.csv`에 입력된 그날의 시편/구약/신약이 표시됩니다.
- 각 항목 옆의 **읽기** 버튼을 누르면 대한성서공회 성경읽기 페이지로 이동합니다.
- 성경 본문은 앱 안에 저장하지 않고, 장절과 링크만 제공합니다.
- 하단 이미지는 `assets/footer_banner.png`로 고정됩니다.

## GitHub 업로드 파일
- app.py
- readings.csv
- requirements.txt
- assets/footer_banner.png

## 통독표 수정 방법
`readings.csv` 파일에서 월, 일, 시편, 구약, 신약을 수정하면 됩니다.
예: `6,11,시68,왕상17-19,살후1`
